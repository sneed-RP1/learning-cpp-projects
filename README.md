# learning-cpp-projects
Just a compilation of all my small C++ projects while i learn the language
# Delta V calculator
- calculates the delta V of a rocket (search up rocket equation for more info)
# Investment calculator
- calculates gains on a given investment with a given interest rate, starting capital and time frame
- can do compounding or simple interest
# Town Sim
- Lets you grow/manage a population
- Goal is to reach 1000 money
- Farms give 5 food and need 3 workers
- Farms cost money which is only made by workers and you start with 100
- If food is positive you gain population if its negative you lose them
- If population is 0 you lose.
